# Contributing

Local Ledger is parked as a product and maintained as a reference implementation, so it is **not
accepting feature pull requests**.

Welcome:

- bug reports with steps to reproduce (please use made-up data, never a real statement);
- small fixes for clear bugs, with a test;
- security or privacy issues, reported privately as described in [SECURITY.md](SECURITY.md).

Before opening a pull request, run `npm run typecheck && npm test && npm run build`.
